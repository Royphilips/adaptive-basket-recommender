# Use of AI tools in this project

This project was built with the help of **Claude**, an AI assistant made
by Anthropic, used through its chat and coding interface. This file
records which elements were created with that tool, as the assignment
requires.

## Elements created with the AI tool

| Element | Files | How the AI tool was used |
|---|---|---|
 `recommender/`, `app_cli.py`, `app_gui.py`, `evaluate.py`, `data/generate_transactions.py`, `tests/test_recommender.py` | Code generated by Claude in the earlier Basket Recommender project, extending the mlxtend example in `original_example/` |
| Shopper profile and learning rules | `adaptive/profile.py`
| Adaptive re-ranking engine | `adaptive/engine.py` 
| Adaptive conversational assistant | `adaptive_cli.py`
| Simulation and chart | `simulate.py`, `results/` 
| Automated tests | `tests/test_adaptive.py` |


## Elements not created with the AI tool

- `original_example/mlxtend_baseline.py` reproduces an example written by
  Sebastian Raschka for the mlxtend documentation (BSD 3-Clause license).
- The Apriori algorithm is by Agrawal and Srikant (1994).

## How the AI-generated code was checked

- 30 automated tests (`python -m pytest -q`) cover the starting system and
  the adaptive layer.
- The assistant was run in scripted sessions, and three problems found
  that way were fixed (see the "Challenges" section of the report).
- The simulation is reproducible from fixed seeds (`python simulate.py`).
